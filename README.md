# Roblox Co-op Horror Game (working title)

A mobile-friendly co-op horror game for Roblox, currently **in development** (target release: December 2026).

## Concept
- Co-op play with solo, duo, trio, and squad modes
- Level-based runs: push for the highest level, restart on death
- Multiple monsters, each with unique abilities and behavior
- Loot and rarity-based progression
- Simple touch controls so it plays well on mobile
- Designed for retention and a wide age range (kid-friendly horror, not gory)

## Tech
- Roblox Studio, Luau
- [Rojo](https://rojo.space/) for syncing scripts to Git (optional)
